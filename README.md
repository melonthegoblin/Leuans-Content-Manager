# Leuans-Content-Manager-Customized-for-KristinaPlaysTheSims
This program serves as an inbetween of manually updating packs, and the Sims 4 Updater. You will still need to download the packs manually, but the program helps with the tedious task of moving the folders where they need to go. The original code for this program was made by Leuan, and modified by me.
